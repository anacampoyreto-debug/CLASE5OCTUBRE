# English Lab · Clase con Leti

Static source code for the interactive English practice site. It uses plain HTML, CSS and JavaScript; it needs no build step or API key.

## Upload to GitHub

1. Create a new repository on GitHub.
2. Upload `index.html` and this `README.md` to the repository root, then commit the files.
3. To publish it as a separate GitHub Pages site, open the repository's **Settings → Pages** and select the `main` branch and root folder as the publishing source.

Progress is stored in the visitor's browser with local storage. Audio and microphone practice depend on browser/device support. The existing Sites deployment and its access settings are separate from this source copy.
